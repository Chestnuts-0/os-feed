声明式 UI 库，组件化写界面的事实标准

简要介绍

把页面拆成可组合的组件，状态变了就自动重绘。生态最大、文档最全，从官网到管理后台都在用。

深度解读

React 把 UI 拆成组件，状态更新后按依赖重绘。这一句在正确排版里会稳定折行——如果打开过程把整页横竖不成比例地拉扁，黄底这四个字会扭、会换位置，结束瞬间再弹回。方案 A / B 里它应从头到尾待在同一处。 第二段继续铺开，好让弹窗比卡片高一截：协调、Hook、并发渲染都是后来加上的能力，阅读时你要的是「这张卡变成这篇」而不是「一篇被压扁的纸再弹开」。
