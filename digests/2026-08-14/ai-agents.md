## 3. 项目进展

今日 **PR 合并/关闭数：112**，其中 **待合并 PR：388**。

**重要进展：**
*   **Gateway 会话修复 (#123192)**：修复了 Gateway 会话在 UI 上显示“假运行中”状态的问题，该问题会导致 Stop 按钮失效，必须重启 Gateway 才能恢复。此 PR 风险等级为 `🚨 session-state`，修复了严重的状态同步问题。

*   **Web UI 交互体验优化**：今日提交了多个针对 Web UI 的修复，包括修复日程选择器在手机屏幕的溢出问题 (#123175)、修复消息加载失败导致预览卡死的问题 (#123324)、修复 IME 输入法组合状态导致的发送键失效 (#123249) 等。

## 5. Bug 与稳定性

**严重程度排序 (P1/P2 为主)：**

1.  **[P1] Subagent 完成消息静默丢失** (#44925, #67777, #92433)
    *   **问题**：Subagent 任务完成后的结果在超时、超载或特定状态下会丢失，既没有重试也没有通知，导致主会话无法获得子任务结果。
    *   **影响**：**Session State / Message Loss**。
    *   **状态**：均有相关 PR 开启，但部分评论指出问题模式复杂，尚未完全解决。

2.  **[P1] Cron Agent 在 DeepSeek 上挂起** (#121953)
    *   **问题**：DeepSeek API 对以 `[cron:` 开头的消息优先级处理不同，导致 Cron Agent 在处理任务时出现长达数分钟的挂起。
    *   **影响**：**Session State**。
    *   **状态**：Open。

3.  **[P1] 多代理并发导致配置覆盖与锁失败** (#43367)
    *   **问题**：在 CLI 并发执行 `agents add` 时，配置文件会被反复覆盖，且会话锁机制不稳定，导致多代理编排不可靠。
    *   **影响**：**Session State**。
    *   **状态**：Open。

4.  **[P1] iOS/WebChat 消息不触发回复** (#97983)
    *   **问题**：官方 iOS 或 WebChat 发送的消息虽然追加到了 transcript，但无法可靠触发 Assistant 回复。
    *   **影响**：**Message Loss**。
    *   **状态**：Open。

5.  **[P1] 多 Agent 并发导致 LLM API 调用全部超时** (#43374)
    *   **问题**：在特定并发场景下，所有 LLM 请求同时超时，虽然 API 本身是通的，但内部调度机制存在问题。
    *   **影响**：**Availability**。
    *   **状态**：Open。

    *   **信号**：这是 Agent 智能体领域的基础能力，若实现将提升系统健壮性。

3.  **LLM 推理流式输出** (#42276)
    *   用户希望像 OpenAI/Grok 那样，看到 Agent 思考过程的流式文本覆盖输出。
    *   **信号**：UX 层面的增强请求，关注推理透明度。

4.  **WebChat 支持 Self-hosted STT/TTS** (#45508)
    *   用户希望 WebChat 前端能通过 Gateway 路由语音识别/合成，而非仅使用浏览器原生 API，以便配合 OpenClaw 的后端配置。
    *   **信号**：打通语音链路，提升多平台一致性。

*   **关于 Web UI**：用户对 UI 的细节体验提出了大量反馈，主要集中在移动端适配（如手机上日程选择器溢出）和输入法兼容性（IME）上，显示出 Web UI 团队正在积极改善用户体验。

## 3. OpenClaw 在生态中的定位

**定位**：生态的“基础设施层”与“核心标准制定者”。

*   **技术路线差异**：与其他项目相比，OpenClaw 更侧重于**后端架构的完备性**（Gateway 通信、会话管理、多模态适配）。它是许多项目（如 NanoClaw, PicoClaw）运行的基础。
*   **优势**：拥有最广泛的社区基础和最复杂的会话管理逻辑，支持跨平台（Android/iOS/Web/CLI）。
*   **挑战**：作为核心组件，其稳定性直接决定生态健康度。目前的“高活跃度”伴随着高 Bug 率，特别是会话状态丢失和消息静默失败，这使其处于“技术债”累积期。

## 4. 共同关注的技术方向

1.  **长上下文与消息丢失**
    *   **涉及项目**：OpenClaw, Hermes Agent, QwenPaw, ZeroClaw
    *   **具体诉求**：Subagent 结果丢失、会话压缩导致历史不可见、长历史下 API 超时。社区普遍在寻找“服务器端压缩”或“智能摘要”机制来解决 Token 限制与上下文连续性的矛盾。

2.  **安全沙箱与权限控制**
    *   **涉及项目**：ZeroClaw, QwenPaw, Hermes Agent
    *   **具体诉求**：高风险 Shell 命令需二次确认、防止恶意插件静默创建任务、防止凭证泄露。这是从“玩具级 Agent”走向“生产级 Agent”的必经之路。

3.  **桌面化与 TUI 体验**
    *   **涉及项目**：Hermes Agent, QwenPaw
    *   **具体诉求**：TUI 界面崩溃/卡死、桌面端启动失败、多任务窗口管理。用户不再满足于简单的命令行，要求具备类似操作系统的交互体验。

4.  **插件生态标准化**
    *   **涉及项目**：ZeroClaw, NanoClaw
    *   **具体诉求**：统一插件接口（如 Agent Plugins 1.0），实现技能包的跨项目复用，降低集成门槛。
