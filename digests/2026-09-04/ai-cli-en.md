## 5. Feature Request Trends

1. **Deep plugin extensibility** — The Function Hooks proposal (#91870) represents the strongest signal: the community wants programmatic, composable hooks into Claude Code's core behavior, not just surface-level customization.
2. **Cross-device / cross-session continuity** — Multiple requests (#47926, #76727) ask for session resumption across devices and coordination between independently-launched sessions sharing a working tree. Heavy users consistently need shared-state primitives.
3. **Subagent plan visibility** — #64062 (closed) highlighted that subagent-generated plans only arrive as text, never populating the Desktop Plan panel. Users want plans surfaced natively.
4. **IDE integration parity** — #70673 requested the VS Code "Generate Commit Message" sparkle button be supported, reflecting demand for feature parity between the Desktop and editor extensions.
5. **Configurable TUI ergonomics** — #64042 (truncation) and #56423 (tool output collapse) both point to a desire for user-controllable display behavior in the terminal UI.
